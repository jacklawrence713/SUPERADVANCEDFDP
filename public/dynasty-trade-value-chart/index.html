Understanding the Dynasty Trade Value Chart

FDP dynasty values range from 0 to 9,999. Elite young players at premium positions score highest. Values account for age (younger = higher), projected points, positional scarcity, and scoring format. The trade value chart updates whenever significant NFL events occur — trades, free agency, injuries, and the draft.

Trade Value Chart by Scoring Format

Fantasy Draft Pros provides trade value charts for every format: PPR (full point-per-reception), Half PPR, Standard (no PPR bonus), Superflex (2QB — boosted QB values), and TE Premium (boosted TE values). Toggle formats instantly at fantasydraftpros.com to see how values change.
